# 🛍️ Tasha Enterprise - E-Commerce Hub

**Tasha Enterprise** is a full-stack e-commerce platform built for modern retail businesses. Designed with both functionality and user experience in mind, this system empowers customers to browse, try on, and purchase products with ease — while also giving admins powerful tools for inventory and order management.

---

## 🚀 Key Features

### 🛒 For Customers
- Browse products by group (Men, Women, Kids) and categories (New In, Sale, Clothing, Shoes, Accessories, Bags)
- Add to cart, checkout, and track orders
- Personal information and address management
- Stripe payment integration (Test Mode)
- Virtual Try-On (powered by FASHN.ai)
- Product recommendation engine
- In-site Chatbot for quick help and queries
- Password reset with OTP via email

### 🛠️ For Admin
- Admin login and dashboard
- Add, edit, delete, and manage products
- Set stock quantities by size (e.g., S, M, L or Shoe sizes)
- View and manage all customer orders
- Add sale price, update stock, delete product images
- Admin dashboard with sidebar navigation

---

## 💻 Tech Stack

### Frontend
- HTML, CSS, Bootstrap
- EJS Templating Engine
- JavaScript

### Backend
- Node.js with Express.js
- MySQL (via `mysql` module)
- Multer for file uploads
- Bcrypt for password hashing
- Nodemailer for emails
- Axios for API calls
- Stripe API for payments
- Replicate & FASHN.ai APIs for virtual try-on
